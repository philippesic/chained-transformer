# Task convention

One `task-name.md` per unfinished multi-session task. An open task is context, not an
instruction to resume it.

Sections, in order: `Goal`, `Authorized` (scope, resources, limits), `Done when` (observable
criteria), `State` (owner, current facts, decisions with dates, blockers; rewrite rather than
append), `Next` (the next action and what it depends on).

Durable conclusions go to `results/<name>/result.md` and a line in [FINDINGS](../FINDINGS.md).
Delete a task file once its criteria are met.
